Design system

A premium, restrained marketplace UI.

Mono ink hierarchy, hairline 1px borders, blue reserved for action. Strict spacing scale. Every component below is a real CSS class — page mockups consume them as-is.

Tokens

Defined as CSS custom properties on :root. Every component reads from these. Theme/density swaps happen by changing tokens, never by overriding component CSS.

/* base */
--bg: oklch(0.155 0.008 260);
--bg-1: oklch(0.190 0.009 260); /* card surface */
--bg-2: oklch(0.225 0.010 260); /* hover surface */
--line: oklch(0.295 0.012 260); /* hairline border */

Buttons

Ghost is default for tertiary actions, secondary for filter / cancel / supporting actions, primary (white-on-black) for confirm, and CTA (blue) reserved for the single most important action on the page — typically buying.

.btn .btn-{ghost|secondary|primary|cta|danger}.btn-sm · .btn-lg · .btn-block

Inputs

Hairline border on flat surface. On focus, border darkens by one step + soft inset glow — never blue (blue means action, not focus).

Nav & tabs

Top nav uses sticky-blur on a near-black surface. Active link gets a 18px blue underline below the row — not a fill, not a glow. Page-level tabs do the same: 2px blue underline, no pill background.

Modal

Centered, single dialog with a blurred scrim. Use for confirmations, two-step flows, and anything that interrupts the current page. Pages, not popups (per feedback_pages_not_popups) — but inline confirmations are fine here.

Tooltip

Inline help — defines a term or explains a number. Triggered by a dashed underline and revealed on hover. Body never wraps; if the explanation is long, use a popover instead.

Float 0.2147 Wear value · 0.00 = factory new, 1.00 = battle-scarred
Pattern 561 Skin pattern index · determines fade / case-hardened look
StatTrak Counter on the weapon — confirmed kills since acquisition

Toast

Transient confirmation in the bottom-right. Up to 4 stacked. Dismiss after 4s default, longer if the message has an action.

New offer of $172.00 on M4A1-S | Hot Rod

Skeleton

Loading placeholder for cards, rows, and inline values. Subtle shimmer to signal motion without seizing attention.

Placeholders

Real placeholders beat fake content. Where the real product needs a skin render or a screenshot, ship a striped block labeled in mono — not a stock photo or hand-drawn cartoon.

[skin: AK-47 | Vulcan FT]
[stall banner 1600 × 320]
[loadout · 5 slots]

This system anchors the redesign. Page mockups (Market, Item Detail, Sell, Profile, Wallet) consume these classes verbatim. To adopt: copy _design.css tokens + components into src/main/resources/static/css/design.css, replacing the corresponding sections.
