00[design system reference]

Design system

Tokens, color, type scale, components, modals, popovers — the source of every other page.

Direction

Mono primary, blue spice. Apple-precision: hairline 1px borders, generous negative space, strict 12 / 14 / 18 / 22 / 28 / 40 / 60 type scale, tabular numerals (Geist Mono) on every price, float, and timestamp.

Color tone Warm cool · hue 260 Chroma ≤ 0.012 on neutrals
Type Geist + Geist Mono Strict 11-step scale
Accent Blue #3b82f6 CTA · live · active tab only
Borders 1px hairline always Elevation via shadow, not weight
