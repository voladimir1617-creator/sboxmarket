API Reference

For bots and browser extensions that use a SkinBox API key.

An API key lets your own script act as your SkinBox account. Create one at Profile → Developers. The full token is shown once, when you create it. Anyone holding it can use your account, so keep it out of public files and chats.

Authentication

Send the token in the Authorization header on every request:

curl https://skinbox.market/api/wallet \
  -H "Authorization: Bearer sbx_live_…"

A key replaces the browser sign-in, so you don't send cookies or a CSRF token. Requests and responses are JSON; send Content-Type: application/json with a body. Prices are in US dollars.

Key scopes

ScopeWhat it can do
RO · read-onlyOnly GET and HEAD requests: prices, listings, your wallet balance, orders and trades. Anything that changes data is refused with RO_KEY_WRITE_FORBIDDEN.
RW · fullEverything below, including buying, selling, bidding and placing buy orders with your wallet balance.

Routes a key can use

The Key column is the scope a route needs. Routes marked RO also work with an RW key.

Website only

These are refused to every API key with API_KEY_FORBIDDEN. Use them signed in on the website.

  • /api/admin and /api/csr: staff tools, for any method.
  • Changes under /api/api-keys, /api/profile, /api/wallet/connect, /api/wallet/withdraw and /api/auth/steam/logout-all: creating keys, account settings (email, trade URL, 2FA), the payout account, withdrawals and signing out everywhere. Reading them with GET still works.

Errors

Errors come back as JSON with a code and a message.

StatusCodeMeaning
401INVALID_API_KEYThe key is unknown or has been revoked.
403RO_KEY_WRITE_FORBIDDENA read-only key tried to change something. Create an RW key for that.
403API_KEY_FORBIDDENThe route is website only (see above).
429RATE_LIMITEDToo many requests. Wait the number of seconds in the Retry-After header, then try again.

Requests are rate limited.
